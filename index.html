Teste 123

1. Escuta Ativa

Praticar empatia no código é ouvir as necessidades reais de quem usa a aplicação antes de tomar decisões de design.

2. Perspectiva do Usuário

Nem todo mundo navega com um mouse ou uma tela de alta resolução. Projetar com empatia é respeitar a diversidade de acessos.

3. Acessibilidade Universal

Acessibilidade não é uma funcionalidade extra; é o padrão básico para garantir que ninguém seja excluído da web.
